ИНФРАСТРУКТУРА

Все боты на одном сервере

🖥️
VPS beget.com
Один сервер — все 4 бота. Автозапуск, постоянная работа, лёгкий деплой.
⚙️
systemd-сервисы
Каждый бот — отдельный .service файл. Автовосстановление при падении.
🧠
Claude API
Мозг Агентуры. Понимает контекст, помнит диалог, говорит по-русски как человек.
💬
python-telegram-bot
v20+, async. ConversationHandler, InlineKeyboard, APScheduler — всё в одном.
🗄️
SQLite
База клиентов в Агентуре. История диалогов, параметры сделок, статусы.
🔒
.env секреты
Токены и ключи вне кода. python-dotenv. Безопасно, легко менять.
